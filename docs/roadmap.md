# Roadmap — Nai's Cafe

> [Proposta] (decisão 10). Cada marco = uma versão com tag, fechada por PR `dev` → `main`. Tasks no [backlog](backlog.md), quebradas pelo AG00 quando o marco começa.

| Marco | Versão | Nome | Foco (etapas da especificação) |
|---|---|---|---|
| M1 | v0.1.0 | Base visual | Tokens, componentes, tela Cafeteria com a sala desenhada, sem clientes; deploy |
| M2 | v0.2.0 | Ciclo principal | Clientes, fila, cartão do pedido, Preparo, moedas, lugares nas mesas |
| M3 | v0.3.0 | Decoração | Decorar, loja, colocação, mudar de lugar, estoque, cores de parede e piso |
| M4 | v0.4.0 | Vida da loja | Clientes da casa, Cardápio, nível e receitas, plantas, gato, áudio, Ajustes |
| M5 | v1.0.0 | Presente | PWA completo, ícones, offline, áreas seguras, animações de toque, teste no iPhone |

Todo marco fecha com uma task de validação (AG06 (QA)) e uma de fechamento (versão, PR, tag) do AG00.
